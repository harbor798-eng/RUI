# RUI

> **Your AI Relationship Assistant**
>
> 一个将众多 Skill 融合的恋爱关系回复助手。
>
> RUI 可以读取微信本地聊天记录，让 AI 从真实对话上下文中生成回复、分析关系。

## 核心功能

- **微信实时消息上下文**：实时读取本地聊天记录，AI 基于真实对话生成建议。
- **多 Skill 回复风格**：内置狗头军师、童锦程视角等 Skill，支持自定义 Skill。
- **前任蒸馏**：基于聊天记录生成人物画像 Skill。
- **详细分析**：情绪、事实、模式多维度分析。

## 许可

本项目仅供学习研究使用。
